### 게임명
게이머 스피드 퀴즈 (가칭)

### 기반
html/css, js

### LLM 활용
- 코드 기초 설계 : GPT Codex 5.3
- 코드 리뷰 및 검토 : Claude Opus 4.6
- 문제 출제 도움 : Gemini 3.1 Pro

### 목적
- 짧은 시간 (1분+@) 체류하게 하지만 그 동안 반드시 광고를 보게 하는 구조로 수익 추구
- 작은 보상을 넣고, 하루 동안 몇 번의 기회를 넣어서 추가 기회를 얻으려면 광고를 시청해야 하는 구조로 수정
- 차후 랭킹 개념을 도입하여 재미 요소 추가

### 게임 규칙
- 각종 게임에 대한 문제로 이루어져 있는, 4지선다 형식의 퀴즈 게임
- 시간 제한 60초를 주고 그 안에 최대한 많이 푸는 방식
- 시작 화면에서 문제의 장르를 선택 가능
- 문제 아래 시간 게이지를 넣어 실시간으로 줄어드는 시간을 표시
- 정답을 맞추면 1초 증가, 오답일 경우 1초 감소
- 모든 문제를 다 풀고 나면 결과 화면에 점수와 정답률 표시 및 룰렛 팝업
- 결과 화면에서 룰렛을 돌릴 수 있고, 1등~3등이 존재.

### 점수 시스템
- 맞춘 문제 1개당 100점을 배점하여, 맞춘 문제 수만큼 점수를 계산
- 단, 문제 1개당 배점은 콤보가 몇이냐에 따라 달라짐
- 5연속 정답부터 은색 콤보, 15연속 정답부터 금색 콤보 발생
- 콤보가 5 이상 14 이하일 때는 문제 1개당 200점을 배점
- 콤보가 15 이상일 때는 정답인 문제 1개당 400점을 배점 (피버 이펙트 발생)
- 문제를 틀릴 경우 틀린 문제 하나당 10점을 감점
- 방치하고 룰렛만 돌리는 걸 막기 위해 점수가 2000점 이상일 경우 룰렛의 1,2등 확률이 2배가 되도록 설정
- 진지한 플레이 유도를 위해 점수당 룰렛 기회를 추가로 제공 (기본 1회, 2000점 이상 시 추가 1회, 4000점 이상 시 추가 2회)

### 그 외 게임 관련 시스템
- 문제 옆에는 전체 유저들의 정답률이 표시됨
- 한 플레이 사이클 안에서는 중복 문제가 나오지 않도록 함
- 4지선다의 보기는 항상 셔플됨
- 남은 시간이 5초 이하로 떨어지면 화면에 붉은 색이 깜빡이고, BGM의 속도가 빨라져 긴박감 제공

### 광고 관련
- 문제를 푸는 동안 아래쪽에는 광고가 상시 표시됨 (16:9, 360x202 사이즈)
- 퀴즈 게임의 한 사이클이 종료되면 '광고 보고 다시 하기' 버튼이 출력됨
- '광고 보고 다시 하기' 버튼을 누를 경우 화면의 가운데에 영상 광고 모달 팝업 오픈
- 정해진 시간 만큼 영상 광고 시청 후에는 '광고 닫기' 버튼이 우상단에 생김
- '광고 닫기' 버튼을 누르면 첫 페이지로 돌아가서 다시 게임을 할 수 있게 됨
- 이미 하루치 게임을 플레이한 상태에서 메인 화면에서 게임 시작할 경우 '오늘의 기회가 모두 소진되었습니다. 추가 기회를 얻으려면 광고를 시청해주세요.' 등의 팝업을 띄워서 시작 화면에서도 광고 팝업 가능하도록

### 그 외
- 핸드폰에서도 쉽게 할 수 있도록 전체 레이아웃을 가로 360x세로 480 정도의 사이즈로 구상 
- 룰렛 1~3등에는 이니 등의 작은 보상을 거는 방향으로 기획
- 무한 이니 파밍이 되면 안되므로 참여 기회는 하루당 2회로 제한을 두고, 광고 시청 1회당 추가 기회 1회, 최대 3회까지 제공하는 방식
- 차후 유저들에게서 문제를 응모받거나, 유저 랭킹 페이지 등도 같이 제공하는 흥미 요소 추가 가능 

### 특이사항
- 원래는 서버단에서 문제와 정답을 주고받아야 하지만 지금은 데모 버전이기 때문에 프론트엔드에서 처리중
- 문제별 정답률의 경우 지금은 로그를 쌓을 수 없으므로 숫자가 랜덤으로 표시되게 처리
- 지금 단계에서 광고를 넣을 수 없으니 퀴즈 아래에 광고 사이즈의 영역만 잡아둠 (16:9 / 360x202) 
- '광고 보고 다시 하기' 버튼으로 팝업되는 영상 광고 모달 또한 임시 영역으로 처리
- 영상 광고 모달은 현재 데모 버전임을 감안하여 2초면 닫히게 되어 있음
